# Norsk: GitHub → обновления → APK → Telegram

## Главное, что ты спрашивал
- **Новые слова и механики НЕ надо скачивать заново.** Ты меняешь файлы в репозитории на GitHub, сайт обновляется сам.
- **APK, который мы сделаем, это «оболочка»**, которая открывает твой сайт. Поэтому новые слова и игры в нём тоже появятся сами. Новый APK нужен только если меняешь название, иконку или Android-настройки.
- Прогресс (знаю / блокнот / XP) хранится в браузере телефона, обновление сайта его не стирает.

---

## Часть 1. Загрузка на GitHub (один раз, ~10 минут)
1. Зарегистрируйся на github.com (бесплатно).
2. Нажми **+ → New repository**. Имя: `norsk`. Поставь **Public**. Нажми **Create repository**.
3. Распакуй `norsk-project.zip` на компьютере. Внутри папка `norsk`: открой её, чтобы видеть `index.html`.
4. В репозитории нажми **uploading an existing file**. Перетащи ВСЁ СОДЕРЖИМОЕ папки (файлы и папку `tools`), не саму папку `norsk`. `index.html` должен лежать в корне репозитория. Нажми **Commit changes**.
   - Папка `.github` (скрытая) иногда не загружается. Если её нет в репозитории, создай файл вручную: **Add file → Create new file**, имя `.github/workflows/audio.yml`, вставь содержимое файла `audio.yml` из проекта.
5. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, папка / (root) → Save.**
6. Через 1–2 минуты сайт открывается по адресу: `https://ТВОЁ-ИМЯ.github.io/norsk/`. Открой и проверь.
7. (По желанию) **Озвучка:** вкладка **Actions → Generate audio → Run workflow**. Через 5–15 минут появится папка `audio/`. Папку `audio` не загружай руками, GitHub в браузере принимает за раз не больше 100 файлов, а их тысячи. Её создаёт Actions сам.

## Часть 2. Как обновлять (каждый раз, когда я присылаю новые файлы)
1. Репозиторий → **Add file → Upload files**. Перетащи новые или изменённые файлы. Файл с тем же именем заменится.
2. **Новый файл со словами** (например `words-b1c.js`) надо ещё подключить. Я каждый раз пришлю уже исправленные `index.html` и `sw.js`, их тоже заменяй.
3. Нажми **Commit changes**. Через минуту сайт обновится.
4. Чтобы телефон подтянул новую версию: открой приложение, закрой и открой ещё раз (из-за кэша обновление видно со второго открытия). Если нет, в `sw.js` увеличь число `norsk-v7` → `norsk-v8`.
5. Маленькая правка одного файла: открой файл → значок карандаша → внеси изменение → **Commit changes**.

## Часть 3. Самый простой способ «приложения» без APK
Открой сайт в Chrome на Android → меню ⋮ → **Добавить на главный экран / Установить приложение**. Появится иконка, откроется на весь экран и будет работать без интернета. На iPhone: Safari → Поделиться → **На экран «Домой»**. (APK на iPhone поставить нельзя.)

## Часть 4. Сделать APK (бесплатно, через PWABuilder)
Нужно: сайт уже открывается по ссылке (часть 1).
1. Открой **pwabuilder.com**, вставь адрес сайта `https://ТВОЁ-ИМЯ.github.io/norsk/`, нажми **Start**.
2. Подожди проверку. Должны быть зелёные пункты: manifest, service worker, иконки. Если что-то красное, скинь мне скриншот.
3. Нажми **Package for stores** → карточка **Android** (Google Play) → **Generate / Download**.
4. В настройках (Options) проверь:
   - **Package ID:** например `io.github.твоёимя.norsk` (потом менять нельзя).
   - **App name:** Norsk. **Version:** 1.
   - **Signing key:** выбери **New** (PWABuilder создаст ключ и положит его в архив).
5. Скачай ZIP, распакуй. Внутри будет файл `.apk` (и, возможно, `.aab`; он нужен только для Google Play) и файл ключа `.keystore` с паролями.
6. **Сохрани ключ `.keystore` и пароли в надёжном месте** (облако, флешка). Если потеряешь, обновить установленное приложение будет нельзя, придётся удалять и ставить заново. Никому ключ не отдавай.
7. Вверху приложения может показываться адресная строка браузера. Это нормально. Чтобы её убрать, нужен файл подтверждения домена (assetlinks.json); для GitHub Pages это неудобно и необязательно, можно пропустить.

## Часть 5. Отправить APK в Telegram и поставить
1. Отправь `.apk` себе в **Избранное** (Saved Messages) в Telegram.
2. На телефоне открой файл в Telegram. Телефон спросит разрешение **«Установка из неизвестных источников»** для Telegram, включи.
3. Может появиться предупреждение Google Play Protect («приложение не проверено»). Нажми **Всё равно установить**.
4. Открой приложение. Друзьям можно переслать этот же файл так же.

## Что когда нужно
| Что изменилось | Нужен новый APK? |
|---|---|
| Новые слова, истории, диалоги, игры, правила | Нет, только обновить файлы на GitHub |
| Новая озвучка | Нет |
| Название, иконка, Package ID | Да |
| Потерян ключ `.keystore` | Придётся удалить приложение и поставить новое |

## Если что-то пошло не так
- Сайт не открывается: подожди пару минут, проверь, что `index.html` лежит в корне репозитория, а Pages включён.
- На телефоне старая версия: открой приложение дважды или увеличь `norsk-vN` в `sw.js`.
- PWABuilder ругается на manifest или иконки: скинь мне скриншот, поправлю.
